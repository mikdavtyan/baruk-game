# Icon Style

The icons must have a **playful mobile game / children's game aesthetic**.

They should NOT look like:

* standard Material Icons
* Lucide icons
* Feather icons
* generic SaaS UI icons
* corporate/productivity app icons
* thin minimalist line icons

## Visual Style

Icons should feel like they belong to a **fun, colorful children's mobile game**.

Think:

* playful
* friendly
* expressive
* slightly cartoon-like
* soft and rounded
* visually interesting
* simple enough to understand immediately
* polished enough to feel like a real mobile game

The icon should have a little bit of **personality**, rather than looking like a generic UI symbol.

## Shape

Use:

* thick, rounded shapes
* soft curves
* rounded corners
* slightly exaggerated proportions
* smooth silhouettes
* simple but recognizable forms

Avoid:

* sharp geometric corners
* extremely thin strokes
* overly technical shapes
* overly detailed illustrations
* perfectly rigid mathematical geometry

## Stroke / Outline

When an outline is used, it should be:

* relatively thick
* rounded
* consistent
* similar to cartoon/game artwork

The outline should contribute to the playful appearance.

Do NOT use extremely thin 1px-style UI strokes.

## Depth

Icons may have subtle visual depth.

Possible techniques:

* small shadow
* subtle offset
* simple highlight
* slightly darker secondary shape
* small 3D/cartoon effect

However, keep the icons readable and not overly realistic.

They should look like **game assets**, not realistic 3D objects.

## Color

Icons can use multiple colors when appropriate.

Prefer:

* cheerful
* playful
* warm
* game-like colors

Avoid making every icon monochrome if a colorful version would fit the visual language better.

Colors should still be consistent across the entire application.

## Personality

The most important rule:

**The icons should feel designed specifically for this game.**

Do not simply take a standard Unicode/Material/Lucide symbol and put it inside the application.

For example, a statistics icon should not look like a generic business analytics icon.

A settings icon should not look like a generic SaaS settings icon.

A help icon should feel like part of the game's world.

## Consistency

All icons must look like they belong to the **same icon family**.

Maintain consistency in:

* outline thickness
* corner roundness
* proportions
* level of detail
* color treatment
* shadows/highlights
* overall cartoon/game aesthetic

When creating a new icon, inspect existing icons first and match their visual language.

## Mobile Readability

Icons must remain recognizable at small sizes.

Primary target sizes:

* 24 × 24 px
* 28 × 28 px
* 32 × 32 px
* 40 × 40 px

Do not add details that disappear or become visually noisy at these sizes.

## Important

The goal is NOT "minimalistic icons".

The goal is:

**Playful + Cartoon + Children's Mobile Game + Polished + Friendly**

Every icon should look like it could naturally appear inside a polished mobile game for children/young users.
