# Theme toggle: every color fades in place

The light/dark toggle used to hide the switch behind a full-screen cover in the new background color, because fading text and its background together takes both through the same gray and the letters vanish for a moment. We went back to a plain per-component fade: every themed color fades in place over a short `THEME_FADE_MS` (300 ms, ease in-out) — View colors on the native driver, Text colors on a JS-driven twin value started with it — and values that can't animate (icon tints, status bar, gradients, PNGs) switch once at the midpoint. We accept the brief low-contrast dip mid-fade (contrast falls to about 1:1 for an instant on light↔dark pairs); keeping the fade short is the mitigation, so don't lengthen it. Considered and rejected: per-token lanes and multi-step text switches to hold contrast throughout — measurably safer, but far more machinery than this is worth.
